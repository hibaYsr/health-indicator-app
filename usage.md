# Application Usage Guide

This document explains how supervisors can use the desktop dashboard.

---

## 1. Login
- Open the Flutter application.
- Login using your Firebase admin credentials.

---

## 2. Viewing Room Status
- The main dashboard shows all rooms.
- **🟢 Green** → Available  
- **🔴 Red** → Occupied  
- Status updates automatically in real time.

---

## 3. Viewing Access Logs
- Click “Access History” tab.
- Filter by:
  - Room
  - Professor
  - Date
- View each access attempt with timestamp and result.

---

## 4. Managing Rooms
- Add new rooms or edit room info.
- Set room to “Maintenance” if temporarily unavailable.

---

## 5. Adding New Users
- Navigate to “Users” tab.
- Add new professors with their RFID card IDs and schedule.

---

## 6. Logging Out
- Click on the profile icon → “Logout”.
- All sessions are securely managed via Firebase Authentication.
